# Suddh Gaav Showcase Website

Single-page React + Vite showcase website for **Suddh Gaav (शुद्ध गाव)** featuring multilingual content (English, Hindi, Marathi), product information, dealership CTA, and contact details.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Placeholder assets
